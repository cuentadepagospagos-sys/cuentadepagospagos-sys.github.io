Blood Strike AI Editor

Automatización privada de grabaciones de videojuegos.

Qué hace

Este proyecto personal utiliza FFmpeg y Rclone en Android para dividir grabaciones sin recodificarlas y transferir los fragmentos a Google Drive del propietario, con el fin de preparar material para edición de videos.

Acceso a Google Drive

La autorización OAuth se utiliza para las operaciones de archivo necesarias para la transferencia. No hay registro público de usuarios ni servicio de edición ofrecido a terceros. Esta página es informativa y no solicita credenciales ni permite subir archivos.

Consulta nuestra política de privacidad para conocer el tratamiento de datos y cómo revocar el acceso.
